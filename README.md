# 地摊大亨90天 (Ditan 90 Days) — V3.0 系统重构版

90年代怀旧街头烟火风单文件 HTML5 经营模拟小游戏（手机/桌面双端自适应，内嵌全套 9 张水粉复古插画，零外部依赖，兼容微信小游戏存储与生命周期）。

- **在线试玩（GitHub Pages）**：https://yeggogg.github.io/ditan90/
- **最新版本文件**：`ditaidaheng_v3.0_mobile.html`（已同步至 `index.html`）

## V3.0 核心更新亮点

1. **工程底座与安全加固（`SAVE_VERSION = 5`）**
   - 抽离单一计算引擎 `evaluateDayPlan(state, plan, mode)`，日结结算、基准推荐与开摊前预览完全同源（常态误差 ≤ 1%）。
   - `SAVE_VERSION = 4 -> 5` 自动迁移：员工存档极简配置化（`{ id, role, hireDay }`），旧档自动剥离硬编码 `capBonus` 并更新 V3.0 目标。
   - 彻底拦截 `__proto__` 车辆 ID 原型污染（内部改用 `Map`）、天气枚举白名单防 XSS、事件倍率 `clamp(0.2, 3.0)`、数组定长截断与第 90 天先扣固定费再自动转入治疗账户。
2. **员工去硬载量化 + 单车设备改造线**
   - 彻底取消员工 `capBonus`，新三角色（初级帮工 ¥75 / 熟练摊手 ¥120 / 全能店长 ¥180）专注疲劳分担、降损耗、高峰转化、大单解锁与多车承载。
   - 单车开放 3 档轻量设备改造（LV1 170 份 / LV2 ¥3,500 210 份 / LV3 ¥8,500 250 份），消除单车 0 员工 vs 2 员工断崖。
3. **四态疲劳排班闭环**
   - 废除花 ¥80 瞬间消灾，改为：全天正常出摊 / 半日轮休（疲劳 40~99，60% 销量，疲劳 -25）/ 主动排休（免摊位费，疲劳 -45）/ 过劳强制歇业（疲劳 100 锁死，医疗违约 ¥180，熟客 -4%，次日仅恢复至 65，车辆状态显示“过劳歇业”）。
   - 第 1~10 天单车疲劳 ×0.75 缓冲，首次达到 70 疲劳弹出一次性排班引导。
4. **地点共享客流池 + 4~6 车非线性瓶颈 + 难度机制化**
   - 每个地点引入每日共享客流池上限，促使多车分散选址与品类分工。
   - 引入车队管理承载 `C_mgmt = 3 + 员工承载 + 备料中心加成`（LV2 +1.5 / LV3 +3.0），超载触发非线性 `coordFactor` 与额外损耗。
   - 四档难度差异化波动振幅、高价熟客阈值、负面事件压力与大单/事件红利；批量推荐降级为常态安全基准。
5. **P3 体验收口**
   - 新开局与清空存档强制重置“隐藏引导”；预测区间加入 `0.14 * |mean|` 底噪校准并保留 `√剩余天数` 收敛；补齐第 90 天余款自动转入说明。
