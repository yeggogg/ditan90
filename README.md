## V2.9 核心升级（全部 20 项 P1–P3 修订）
- **P1 纠偏与难度校准**：移除同址批量推荐多余的 `crowdSplit` 系数并将推荐备料设为期望需求的 1.12 倍（降低早期破产率、回升推荐玩法表现）；重校准四档难度目标与启动资金，收窄单车 0 员工与 2 员工差距。
- **P2 逻辑与稳健性**：补齐单车存档车辆数上限、数组长度与车辆 ID 唯一性校验（CX-01）；校验 `cityHeat` 防 `NaN` 写入备料（CX-02）；一键备货受 2000 上限或现金限制未补齐时准确提示（CX-03）；价格反馈结合实际分配库存并统一绿区 1.10–1.25 倍（CX-04）；老板疲劳 100 直接禁用开摊按钮；禁止把最后一辆在营车转型掉；天气/事件/车辆 ID 转义。
- **P3 体验与 UI**：预测区间改按 `√剩余天数` 缩放（NV8-03）；第 90 天无货全转归类为“时间到”而非“破产”（NV8-06），且终局结算自动计入剩余可用现金；资金页红点对齐第 90 天无预留规则（NV8-05）；持久化“隐藏引导”（NV8-07）；统一单车雇人上限显示 0/2人；提升 LV2 备料中心性价比（造价 ¥4,500、维护 ¥40/日、熟料损耗降至 22%）；日结对高度疲劳（≥80）提前预警，修复第 90 天结算后剩余 0 天、不出摊免摊位费提示与防删 `restUsedToday` 刷次数。
