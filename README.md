# 地摊大亨90天 · 手机版 V2.5

90年代街头怀旧风单文件 HTML5 模拟经营网页游戏（零外部依赖，适配手机竖屏与 320px 窄屏）。

## 在线试玩
- GitHub Pages：https://yeggogg.github.io/ditan90/

## 文件说明
- `index.html`：手机版网页游戏主入口（V2.5）
- `ditaidaheng_v2.5_mobile.html`：V2.5 版本归档文件

## 核心特性（V2.5）
- 四档难度（新手/普通/熟练/专家）与单车精耕挑战模式
- 90天阶段节奏：第1–10天烧烤起步，第11天解锁小吃/饮品/冷饮与摊位转型
- 固定 Seed 天气与城市事件系统、6车管理费与第六车保障费单列、LV2/LV3 中央备料中心四条件升级评估
- 严格总账与分车对账核验、第14天起白话经营预测、内置 A/B/C 策略同 Seed 快测与本地 VERSION=4 存档
