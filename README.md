## V2.8 核心升级（11项修订 + 新手体验优化）
- **P1 必修**：第 90 天终局解除次日进货预留金锁，支持将手头现金全部转入治疗账户；单车目标比例回调至 0.50 并整体重校准四档难度梯度；读档校验阶段按模式上限（单车 2 人 / 多车每车 1 人上限 6 人）硬截断员工列表（NV-01）。
- **P2 逻辑**：“歇一会”限每日最多 2 次且同日费用递增（¥80 → ¥180，NV-06）；批量推荐合并同地点多车竞争与客流分摊（NV-04）；补全空仓且现金不足购买最便宜单份原料的破产边界（NV-02）。
- **P3 体验与新手优化**：过劳 100 强制歇业在日结显式标明原因；经营预测三档区间改按近期净利标准差动态计算（NV-05）；修复搬点/转型提示二次 HTML 转义（NV-03）；第 85 天起终局冲刺提示与第 90 天全额转入提示；整合前 3 天新手引导、即时定价比价口碑指示灯、底部红点提示、固定开支预览与画布吆喝互动。
- **包装耗材费说明**：本版本保留每售出 1 份 ¥0.6 包装耗材费（单列现付、不与原料采购重复扣款），纯单车路线收益较无包装费口径约降 9%–11%，已同步纳入单车 0.50 目标比例与难度校准。
