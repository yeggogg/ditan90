## V2.6 核心升级
- **P0 经济防线与防卡死**：按摊型显式预分配库存杜绝同类车超卖；原料仅在采购时按锁定折扣单次扣款；新增“今天不出摊直接结算”兜底、开摊前破产检测与自定义采购量；校准单车精耕挑战目标。
- **P1 平衡与决策深度**：移除高价 0.28 保底并建立地点弹性定价曲线与标价上限提示；新增明日天气与城市事件预告、高价流失熟客机制与高频批量订单；员工实质增载量与多车协同；老板疲劳分档惩罚与 100 强制休整；修复 LV2 利用率并按真实成本核算 LV3 节省。
- **P2 账本与稳健性**：日结新增“公共费用/未分摊公共净利”行严格对账；经营预测精度到元并严格对齐近14天与剩余营业日；强化坏档校验与自动备份、日结每日一次守卫与转账防重入锁、新开局覆盖确认及切后台停帧。
- **P3 UI/UX**：桌面宽屏双列响应式、允许移动端缩放、多车折叠卡片与“沿用昨日/批量推荐”、满车显示“车队已满”、转型/搬点展示当前状态、标题页隐藏顶栏假数据并补齐内嵌 favicon。
